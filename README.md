# 모임 경비 정산 웹앱

**총무 1명**이 모임·여행 중에 결제할 때마다 입력하고, 끝나면 **1/n 금액과 입금 현황**을 한 번에 정리하는 웹앱입니다.

- 결제할 때 **현재 위치 주변 식당·장소를 바로 검색해 고르고** 금액만 넣으면 됩니다.
- 여러 모임을 목록으로 관리합니다. 모임마다 **숫자 4자리 비밀번호**를 걸고, 목록에서 열 때마다 비밀번호를 묻습니다.
- 정산이 끝나면 **정산 완료**로 표시해 보기 전용으로 보관합니다. 필요하면 다시 열 수 있습니다.

## 파일 구성

| 파일 | 용도 |
|---|---|
| `index.html` | 앱 본체 (수정할 필요 없음) |
| `config.js` | 카카오 키, Firebase 설정 — **이 파일만 고치면 됩니다** |
| `firestore.rules` | Firestore 보안 규칙 |

설정 없이 열어도 동작합니다. 이때는 장소 검색 없이 **이 기기(브라우저)에만 저장**됩니다. 총무 혼자 휴대폰 하나로 쓴다면 Firebase 없이 이 모드로 충분합니다. 다만 브라우저 데이터를 지우면 사라지니, 목록 화면 아래의 **백업 파일 저장**을 가끔 눌러 두세요.

---

## 1. 카카오 장소 검색 켜기 (약 10분)

1. https://developers.kakao.com 에 로그인한 뒤 **내 애플리케이션 → 애플리케이션 추가하기**를 누릅니다.
2. 앱 관리 페이지에서 **[카카오맵] → [사용 설정]의 상태를 ON**으로 바꿉니다. 이걸 켜지 않으면 지도가 뜨지 않습니다.
3. **[앱 키]**에서 **JavaScript 키**를 복사합니다. REST API 키가 아닙니다.
4. JavaScript 키 설정의 **JavaScript SDK 도메인**에 앱을 올릴 주소를 등록합니다.
   - 예: `https://moim.example.com`, `https://아이디.github.io`
   - PC에서 테스트할 때 쓸 `http://localhost:8080`도 함께 등록해 두면 편합니다.
5. `config.js`의 `KAKAO_JS_KEY: ''` 따옴표 안에 키를 붙여넣습니다.

> 무료 쿼터는 개발자 계정당 **처음으로 카카오맵을 켠 앱**에만 주어집니다. 사용량은 앱 관리 페이지의 [통계] → [쿼터]에서 확인합니다.
> 카카오 정책상 검색 결과(주소, 좌표 등)는 따로 저장하면 안 됩니다. 그래서 이 앱은 지출에 **장소 이름과 카카오맵 링크만** 남깁니다.

## 2. (선택) 여러 기기에서 같은 목록 보기 — Firebase (약 10분, 무료 플랜으로 충분)

1. https://console.firebase.google.com 에서 **프로젝트 추가**를 누릅니다. Google 애널리틱스는 꺼도 됩니다.
2. **빌드 → Firestore Database → 데이터베이스 만들기**를 누릅니다. 위치는 `asia-northeast3 (서울)`, 모드는 프로덕션을 고릅니다.
3. Firestore의 **규칙** 탭에 `firestore.rules` 내용을 그대로 붙여넣고 **게시**합니다.
4. **프로젝트 설정(톱니바퀴) → 내 앱 → 웹(</>)**에서 앱을 등록하고, 표시되는 `firebaseConfig` 값을 복사합니다.
5. `config.js`의 `FIREBASE: null`을 아래처럼 바꿉니다.
   ```js
   FIREBASE: {
     apiKey: 'AIza...',
     authDomain: '프로젝트ID.firebaseapp.com',
     projectId: '프로젝트ID',
     appId: '1:...:web:...'
   }
   ```
   Firebase 웹 apiKey는 공개되어도 괜찮은 값입니다. 실제 접근은 보안 규칙이 막습니다.

PC와 휴대폰 등 여러 기기에서 같은 모임 목록을 보고 싶을 때만 설정하면 됩니다.

**보안 참고:** 4자리 비밀번호(총무용·입력용)는 화면에서 기능을 나누는 용도이고, 암호화하지 않은 **화면 잠금**입니다. Firebase 모드에서는 사이트 주소를 아는 사람이 개발자 도구로 데이터를 읽을 수 있으니, 주민번호처럼 민감한 정보는 넣지 마세요.

## 3. 사이트에 올리기

위치 검색(GPS)은 브라우저 정책상 **https 주소**에서만 동작합니다. 셋 중 편한 방법을 고르세요.

**A. Firebase Hosting** — Firebase를 쓴다면 가장 간단합니다.
```bash
npm install -g firebase-tools
firebase login
firebase init hosting      # public 폴더로 이 폴더 지정, SPA 질문은 No
firebase deploy
```
배포 후 나오는 `https://프로젝트ID.web.app` 주소를 카카오 JavaScript SDK 도메인에 등록합니다.

**B. GitHub Pages** — 저장소에 세 파일을 올리고 Settings → Pages에서 켜면 `https://아이디.github.io/저장소명/`으로 열립니다.

**C. 회사·개인 서버(nginx 등)** — 정적 파일 3개를 웹 루트에 두기만 하면 됩니다. 인증서(https)는 꼭 적용하세요.

**PC에서 먼저 테스트:** 이 폴더에서 `python3 -m http.server 8080`을 실행하고 http://localhost:8080 을 엽니다. localhost에서는 http여도 위치 검색이 됩니다.

## 쓰는 법

1. **+ 새 모임**에서 이름, 날짜, 참여자, 총무, 비밀번호를 넣습니다. 비밀번호는 두 가지입니다.
   - **총무 비밀번호**: 모든 기능을 쓸 수 있습니다(수정·삭제, 설정, 입금 확인, 정산 완료).
   - **입력용 비밀번호**(선택): 일행에게 알려 주는 번호입니다. 지출 **추가**만 할 수 있고, 자기 폰에서 넣은 지출만 고칠 수 있습니다. 정산 화면은 볼 수 있지만 카톡 정산 문구 보내기는 총무만 할 수 있습니다.
   - **개인**은 이름을 직접 입력하고, **단체**는 단체명과 인원수를 넣습니다(예: 산악회 5명). 단체는 인원수만큼 1/n을 부담하고, 정산 화면과 카톡 문구에 개인·단체가 나뉘어 표시됩니다.
2. 결제할 때마다 **내 주변 식당·장소 찾기** → 장소 선택 → 금액 → **저장**을 누릅니다.
   - 결제한 사람은 기본이 총무입니다. 다른 사람이 대신 낸 경우에만 바꾸면 그만큼 빼고 계산합니다.
3. **정산** 탭에서 `총액 ÷ 인원 = 1인 금액`을 확인합니다. 끝전은 기본으로 100원 단위에서 올리며, 1원·10원·1,000원 단위로 바꿀 수 있습니다.
4. 정산 화면의 **총무 한마디** 칸에 공지나 인사말을 적고(분류별 합계 포함 여부도 체크로 선택) **정산 문구 보내기**로 카톡방에 보내고, 입금이 들어오면 이름 옆 **미입금** 버튼을 눌러 **완료**로 바꿉니다.
5. 다 받으면 **정산 완료 처리**를 누릅니다. 목록의 '정산 완료'로 옮겨져 보기 전용이 됩니다.
6. 모임을 만들 때나 설정에서 **은행·계좌번호·예금주**와 **입금 안내 문구**(예: "카톡으로 송금해 주세요")를 넣으면 정산 화면에 **계좌 복사** 버튼이 생기고, 정산 문구에도 함께 표시됩니다. 참여자 추가·삭제, 총무 변경, 비밀번호 변경도 설정에서 합니다.

> 비밀번호를 잊으면 이 앱 안에서는 찾을 수 없습니다. 이 기기 모드라면 **백업 파일 저장**으로 받은 JSON 파일에서 `"pin"` 값을 확인할 수 있습니다.

휴대폰 브라우저 메뉴에서 **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있습니다.

## 데이터 구조 (Firestore)

```
groups/{모임ID}                 name, date, members[], treasurer, pin, unit, status, checks{}, account, total, count
groups/{모임ID}/expenses/{ID}   amount, title, payer, cat, date, ts, place{id,name,url}
```
